# erikdellenback.com

Personal website for Erik Dellenback. A single static page, no build step, hosted on GitHub Pages.

## What is here

```
index.html                 the whole site (sections: hero, people, listen, story, work, footer)
css/site.css               all styles; design tokens are the CSS variables at the top
images/                    responsive WebP + JPEG renditions generated by scripts/optimize-images.py
favicon.svg                browser tab icon
CNAME                      tells GitHub Pages which custom domain serves this site
.nojekyll                  tells GitHub Pages to serve files as-is (no Jekyll processing)
robots.txt, sitemap.xml    search engine basics
scripts/optimize-images.py turns a source photo into the sizes the page expects
docs/design-handoff/       the original design files this page was built from
docs/ASSESSMENT.md         review of the current design and recommended changes
```

Raw photo originals and Erik's CV stay in the parent folder on Wyatt's machine. They are not committed.

## Editing the site

Everything visible is in `index.html`. Each section is marked with a banner comment.

- **Copy**: edit the text directly. The design rule is no em dashes anywhere.
- **Work list**: add or remove `<li>` rows under `#work`.
- **Footer links**: replace the `#` placeholders for Instagram, X and LinkedIn with real URLs.
- **Listen section**: it is in the page but has the `hidden` attribute. Remove `hidden`, then fill in each clip's link, title, meta line and thumbnail.
- **Hero video**: a commented-out `<video>` block sits in the hero. Drop an MP4 into `media/hero.mp4`, uncomment, done. The still image stays as the poster.
- **Colors and type**: change the variables at the top of `css/site.css`.

### Adding or swapping a photo

```bash
python scripts/optimize-images.py "path/to/New Photo.jpg"
```

That writes `images/new-photo-640.webp`, `-1024`, `-1600`, `-2200` (whichever fit the original) plus JPEG fallbacks. Then point a `<picture>` block in `index.html` at the new name. Requires Python 3 and Pillow (`pip install pillow`).

### Preview locally

```bash
python -m http.server 8000
```

Open http://localhost:8000.

## Deploying

The site deploys from the `main` branch, root folder. Every push to `main` goes live within a minute or two.

First-time setup, from this folder:

```bash
gh auth login
gh repo create erikdellenback.com --public --source=. --remote=origin --push
gh api -X POST repos/{owner}/erikdellenback.com/pages -f "source[branch]=main" -f "source[path]=/"
```

GitHub Pages on a free account requires the repository to be public. Nothing private is in this repo.

## Pointing the domains at the site (GoDaddy)

GitHub Pages serves one custom domain per site. `erikdellenback.com` is the primary (that is what the `CNAME` file says). The other two domains forward to it.

### erikdellenback.com

In GoDaddy DNS for erikdellenback.com, delete any existing `A` record for `@` and any parked-page forwarding, then add:

| Type  | Name | Value                    | TTL  |
|-------|------|--------------------------|------|
| A     | @    | 185.199.108.153          | 600  |
| A     | @    | 185.199.109.153          | 600  |
| A     | @    | 185.199.110.153          | 600  |
| A     | @    | 185.199.111.153          | 600  |
| CNAME | www  | `<github-username>.github.io` | 600 |

Then in the GitHub repo: Settings, Pages, Custom domain: `erikdellenback.com`, Save. Wait for the DNS check to pass (usually minutes, up to 24 hours), then tick **Enforce HTTPS**. `www.erikdellenback.com` will redirect to the apex automatically.

Verify from a terminal:

```bash
nslookup erikdellenback.com
```

You should see the four 185.199.x.153 addresses.

### dellenback.com and hatnhoodie.com

In GoDaddy for each domain: Domain settings, Forwarding, add a permanent (301) forward to `https://erikdellenback.com`, with "Forward only" (not masking). GoDaddy handles the redirect on its own servers, so no DNS records are needed beyond what it sets up itself.

If Hat n Hoodie later becomes its own consulting site, take the forward off hatnhoodie.com and give it its own repo and `CNAME`.
